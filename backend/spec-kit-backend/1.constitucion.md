# Constitución del backend

## 1. Propósito

Construir una API REST para administrar productos de una tienda de electrónica y permitir el acceso seguro de administradores.

## 2. Tecnologías obligatorias

- **Lenguaje:** TypeScript.
- **Runtime:** Node.js.
- **Capa HTTP:** Hono.
- **Autenticación:** JWT.
- **Hash de contraseñas:** bcrypt con 8 saltos (`salt rounds = 8`).
- **Validación:** Zod.
- **Base de datos:** PostgreSQL.
- **Despliegue:** Vercel.

## 3. Principios de desarrollo

- Mantener separación estricta entre HTTP, reglas de negocio y acceso a datos.
- Validar todas las entradas externas con esquemas Zod.
- Nunca guardar ni devolver contraseñas en texto plano.
- Mantener secretos y credenciales únicamente en variables de entorno.
- Usar respuestas HTTP y formatos JSON consistentes.
- Aplicar autenticación a todas las operaciones de escritura de productos; las consultas del catálogo podrán ser públicas.
- Mantener funciones pequeñas, tipadas y fáciles de probar.

## 4. Arquitectura aprobada

Se utilizará una arquitectura de tres capas:

1. **Presentación:** rutas, controladores y middleware HTTP de Hono.
2. **Aplicación:** servicios con las reglas de negocio.
3. **Persistencia:** repositorios y conexión con PostgreSQL.

Los esquemas de Zod serán compartidos por la presentación y los servicios cuando sea necesario. Las entidades de dominio no dependerán directamente de Hono.

## 5. Criterios de seguridad

- El JWT se firmará con un secreto configurado mediante `JWT_SECRET`.
- El JWT tendrá una expiración configurada mediante `JWT_EXPIRES_IN`.
- La contraseña se comparará mediante bcrypt y nunca mediante texto plano.
- El costo de bcrypt será configurable, con valor obligatorio de 8.
- Los endpoints de productos requerirán un JWT válido.

## 6. Compatibilidad con Vercel

La aplicación Hono se exportará como `default` y no utilizará `app.listen()` en producción. Se utilizará el adaptador o plantilla oficial de Hono para Vercel y el runtime de Node.js, necesario para una integración estable con `bcrypt` y PostgreSQL.
