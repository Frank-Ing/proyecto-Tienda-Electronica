# Tareas de implementación

## Fase 1: Proyecto

- [ ] Inicializar `package.json`.
- [ ] Instalar TypeScript, Hono y dependencias base.
- [ ] Crear `tsconfig.json` con modo estricto.
- [ ] Crear configuración de ESLint y Prettier.
- [ ] Crear `app.ts` e `index.ts`.
- [ ] Configurar exportación `default` de Hono para Vercel.
- [ ] Implementar `GET /health`.

## Fase 2: Persistencia

- [ ] Instalar y configurar el cliente PostgreSQL.
- [ ] Validar `DATABASE_URL`.
- [ ] Crear módulo de conexión.
- [ ] Crear `admin.repository.ts`.
- [ ] Crear `product.repository.ts`.
- [ ] Usar consultas parametrizadas.
- [ ] Preparar seed del administrador con contraseña bcrypt.

## Fase 3: Seguridad

- [ ] Implementar `password.ts`.
- [ ] Configurar bcrypt con `BCRYPT_ROUNDS=8`.
- [ ] Implementar firma de JWT.
- [ ] Implementar verificación de JWT.
- [ ] Crear `auth.middleware.ts`.
- [ ] Definir duración del token.
- [ ] Evitar devolver `contrasena` en las respuestas.

## Fase 4: Autenticación

- [ ] Crear `auth.schema.ts`.
- [ ] Crear `auth.service.ts`.
- [ ] Crear `auth.controller.ts`.
- [ ] Crear `auth.routes.ts`.
- [ ] Implementar `POST /api/auth/login`.
- [ ] Implementar `POST /api/auth/logout`.
- [ ] Responder con `401` para credenciales inválidas.

## Fase 5: Productos

- [ ] Crear `product.schema.ts`.
- [ ] Crear `product.service.ts`.
- [ ] Crear `product.controller.ts`.
- [ ] Crear `product.routes.ts`.
- [ ] Implementar `POST /api/products`.
- [ ] Implementar `PATCH /api/products/:id`.
- [ ] Implementar `DELETE /api/products/:id`.
- [ ] Implementar `GET /api/products`.
- [ ] Implementar filtros `modelo` y `categoria`.
- [ ] Proteger todas las rutas de productos con JWT.

## Fase 6: Calidad

- [ ] Crear middleware global de errores.
- [ ] Estandarizar respuestas JSON.
- [ ] Agregar pruebas unitarias.
- [ ] Agregar pruebas de integración HTTP.
- [ ] Probar casos de datos inválidos.
- [ ] Probar acceso sin token y con token vencido.
- [ ] Probar productos inexistentes.

## Fase 7: Producción

- [ ] Configurar variables de entorno en Vercel.
- [ ] Confirmar Node.js Runtime.
- [ ] Verificar conexión con PostgreSQL de producción.
- [ ] Ejecutar compilación de producción.
- [ ] Desplegar y probar la API.
