# Plan de construcción

## Fase 1: Inicialización

- Crear el proyecto TypeScript.
- Configurar Hono con plantilla compatible con Vercel.
- Configurar scripts de desarrollo, compilación y producción.
- Configurar ESLint, Prettier y TypeScript strict.
- Crear endpoint `GET /health`.

## Fase 2: Configuración y base de datos

- Validar variables de entorno con Zod.
- Configurar conexión PostgreSQL.
- Integrar las tablas de administrador y producto.
- Crear repositorios con consultas parametrizadas.
- Preparar seed del administrador.
- Generar el hash de contraseña con bcrypt y 8 saltos.

## Fase 3: Autenticación

- Crear esquema Zod para login.
- Consultar el administrador por usuario.
- Comparar contraseña con bcrypt.
- Generar y verificar JWT.
- Crear middleware de autorización.
- Implementar login y logout.

## Fase 4: Gestión de productos

- Crear esquemas Zod para alta y actualización.
- Implementar registro de productos.
- Implementar actualización parcial.
- Implementar eliminación.
- Implementar listado.
- Implementar filtros por modelo y categoría.

## Fase 5: Errores y seguridad

- Crear manejador global de errores.
- Uniformar respuestas y códigos HTTP.
- Evitar exponer contraseñas y secretos.
- Validar parámetros de ruta y query string.
- Revisar consultas SQL y control de acceso.

## Fase 6: Pruebas

- Probar esquemas Zod.
- Probar hash y comparación de contraseñas.
- Probar generación y validación de JWT.
- Probar servicios con repositorios simulados.
- Probar endpoints autenticados y no autenticados.
- Probar filtros y errores de validación.

## Fase 7: Despliegue

- Configurar PostgreSQL de producción.
- Configurar variables de entorno en Vercel.
- Ejecutar build de producción.
- Desplegar con Vercel.
- Verificar health check y endpoints principales.
